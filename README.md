# YouTube Downloader (YTDownloader) v2.0 - Seal / yt-dlp Architecture

Автономное Android-приложение для скачивания любых видео и аудио с YouTube (включая Shorts) на базе архитектуры **Seal** (встроенный локальный движок `yt-dlp` и `FFmpeg`).

## Ключевые возможности

1. **Архитектура Seal (локальный yt-dlp + FFmpeg)**:
   - Приложение больше не зависит от сторонних серверов, прокси или загрузчика DownloadManager.
   - Скачивание, обход шифрования сигнатур YouTube и объединение видеодорожки с аудиопотоком выполняются напрямую на процессоре смартфона.
   - **Никаких ошибок 403 Forbidden и битых файлов по 11 КБ!**
2. **Выбор качества и форматов**:
   - `1080p Full HD` (полноценное видео со звуком, автоматически склеивается через FFmpeg).
   - `720p HD` (быстрое скачивание с высоким качеством).
   - `480p SD` и `360p` (для экономии памяти и мобильного трафика).
   - `Аудио (MP3)` (прямое извлечение чистой звуковой дорожки).
3. **Отображение прогресса**:
   - Реальный процент скачивания прямо на экране в реальном времени.
4. **Сохранение в системную папку «Загрузки»**:
   - Видео сразу появляется в галерее и доступно офлайн.
5. **Постоянный сертификат подписи**:
   - В проект встроен ключ `app/debug.keystore` — приложение устанавливается поверх предыдущих версий как штатное обновление.

## Сборка через GitHub Actions

1. Распакуйте архив `YTDownloader_Project_v2.0_SEAL.zip`.
2. Загрузите всё содержимое папки `YTDownloader` (`Ctrl + A`) в ваш репозиторий на GitHub через кнопку **Add file** → **Upload files**.
3. Нажмите **Commit changes**.
4. GitHub Actions автоматически скомпилирует приложение во вкладке **Actions** и предоставит готовый файл `YTDownloader-debug-apk`.
