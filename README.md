# YouTube Downloader (YTDownloader) - Android Project

Современное минималистичное Android-приложение для скачивания видео и аудио с YouTube (включая Shorts) с возможностью **выбора качества видео** и **предварительным отображением размера файла**.

## Ключевые возможности

1. **Выбор качества видео перед скачиванием**:
   - `4K Ultra HD (2160p)` (сверхчёткое разрешение 4K).
   - `2K Quad HD (1440p)` (повышенная чёткость 1440p).
   - `1080p Full HD` (высокое разрешение для больших экранов).
   - `720p HD` (оптимальный баланс качества и скорости).
   - `480p SD` и `360p` (экономия трафика и памяти смартфона).
   - `Аудио (MP3)` (скачивание только звуковой дорожки).
2. **Предварительный расчёт и показ размера файла**:
   - Размер файла отображается прямо в выпадающем списке рядом с каждым качеством (например: `4K Ultra HD (~1.35 ГБ)`, `1080p Full HD (~75.4 МБ)`, `720p HD (~42.1 МБ)`, `MP3 (~4.5 МБ)`).
3. **Интеллектуальное отображение времени скачивания**:
   - Примерное оставшееся время автоматически форматируется в секунды (`~45 с`), минуты и секунды (`~8 мин 20 с`) или часы и минуты (`~1 ч 15 мин`).
4. **Эргономичный ввод и предпросмотр**:
   - Кнопка быстрой вставки из буфера обмена («Вставить»).
   - Карточка предпросмотра: обложка ролика в высоком разрешении, название видео и автор канала.
   - Поддержка ссылок любого формата: `youtube.com/watch?v=...`, `youtu.be/...`, `youtube.com/shorts/...`, а также кнопки «Поделиться» напрямую из официального приложения YouTube.
5. **Тумблер темы (Авто / Тёмная / Светлая)**:
   - Равномерно распределенный тумблер с сохранением выбора темы между запусками.
6. **Поддержка разработчика**:
   - Встроенная кнопка поддержки через сервис **CloudTips**.
7. **Постоянный сертификат подписи**:
   - В проект встроен постоянный ключ `app/debug.keystore`, благодаря чему любые последующие обновления будут устанавливаться «поверх» без ошибок конфликта пакетов.

## Сборка через GitHub Actions (в 1 клик)

1. Создайте новый репозиторий на GitHub (например, `YTDownloader`).
2. Распакуйте архив `YTDownloader_Project.zip` на компьютере.
3. Зайдите внутрь распакованной папки, выделите всё содержимое (`Ctrl + A`) и загрузите на GitHub через кнопку **Add file** → **Upload files**.
4. GitHub Actions автоматически скомпилирует приложение во вкладке **Actions** и предоставит готовый файл `YTDownloader-debug-apk`.
